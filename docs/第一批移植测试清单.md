## E. #8212 GeneratorExit 工具流（GE）

**修复点**：`agents/tools/run_tool_batch.py`、`tool_calls/_coordinator.py`、
`runtime/runtime.py`；新增统一的"终止后 drain（带上限）"辅助。

| ID | 场景 | 输入 | 期望 | 结果 |
| --- | --- | --- | --- | --- |
| GE-01 | **复现**（不依赖 AgentScope） | 假生成器：`try: yield interrupted finally: yield response`，在 interrupted 处 `aclose()` | 修复前：`RuntimeError: async generator ignored GeneratorExit`；修复后：正常耗尽 | ✅ |
| GE-02 | `_call_tool` 接线 | 模拟 INTERRUPTED + finally yield | 无 RuntimeError，返回 interrupted response | ✅ |
| GE-03 | drain 上限 | 终止后继续产出 10000 个 chunk | 最多再读 N 个 / T 秒后停止，不无限消费 | ✅ |
| GE-04 | `runtime.py` GeneratorExit | 消费方关闭流 | 进入 GeneratorExit 分支，保存后重新抛出，**不 yield** | ✅ 结构守卫 |
| GE-05 | 正常完成不回归 | 普通工具流 | 事件序列与修复前一致，最终 response 不丢 | ✅ |
| GE-06 | 变异 | 把 drain 改回 `close()` | GE-01/GE-02 失败 | ✅ |
| GE-07 | 回归 | `tests/unit/agents`、`tests/unit/tool_calls`、`tests/unit/runtime` | 全绿 | ✅ |

**风险观察**：drain 上限是本地加的（上游没有）。上限值可配置（默认 64 个 chunk / 2 秒），
超限写 warning 并继续流程，不阻塞用户。
