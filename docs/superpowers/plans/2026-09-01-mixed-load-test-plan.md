## 一、测试目标

在接近真实业务的数据体量下，验证数据分析模块与知识空间模块的**功能性**与**性能**，暴露“真正用起来会遇到”的问题。

- 数据分析：≥10 张业务表，总数据量 ≥100 万行。
- 知识空间：多品类文档（科技、体育、财经、政务、医疗等），用于验证检索召回与 RAG 质量。
- 所有数据通过**真实 API** 创建/导入/上传，覆盖完整链路。

### 发现并已修复的问题

| 严重度 | 问题 | 处理 |
|--------|------|------|
| 🔴 严重 | **堆叠 SQL 注入**：`SELECT * FROM t; DROP TABLE t` 通过校验被执行，psycopg2 不拦截，实际导致 300k 行表被 DROP | 已修复 `_is_read_only`（检测分号拒绝多语句），已提交 `f6e03c11` |
| 🔴 严重 | **中文混合大小写列名导入失败**：INSERT 未对列名加引号，PG 将 `订单ID` 折叠为 `订单id` | 已修复 `_batch_insert` 引号列名，已提交 `6db44af0` |
| 🟡 轻微 | LIMIT 检测对字符串里的 "LIMIT" 误判 | 已优化为词边界匹配（`\bLIMIT\b`） |
