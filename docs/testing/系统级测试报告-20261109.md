### 3.4 工作区文件规范

新增了“结果/脚本分离”规则，避免工作区根目录继续堆积生成文件：

- **提示词强制**：`WorkspaceLayoutContributor` 要求所有生成结果写入
  `outputs/`，所有中间代码写入 `scripts/`，禁止在根目录、`upload/`、
  `media/` 新建文件；
- **沙箱强制**：普通用户 shell 只对 `outputs/`、`scripts/` 授予写权限，
  工作区根目录仍为只读；
- **文件工具强制**：普通用户通过 `write_file` / `edit_file` / `append_file`
  写文件时，只允许落到 `outputs/`、`scripts/`（`AGENTS.md`、`SOUL.md`、
  `PROFILE.md` 除外），否则返回可读的拒绝信息；
- **测试**：新增 `test_generated_files_must_use_outputs_or_scripts`、
  `test_edit_file_cannot_rewrite_uploaded_or_root_files`、
  `test_workspace_layout_forces_outputs_and_scripts`；
- 全量单元测试 7867 passed，P0 失败集合与改动前完全一致。
- `HUIZHI_SANDBOX_LANDLOCK` 默认 `0`：openEuler 5.10 无 Landlock 时走
  UID/组权限 + seccomp；已验证 A 不能读 B、media/upload 只读、outputs/scripts
  可写、网络被拒绝；`1` 才要求 Landlock，不支持时失败关闭。
