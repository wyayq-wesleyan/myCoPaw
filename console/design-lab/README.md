# Design Lab · 政务专业方向

这是汇智小助手正式平台化改造前的**独立界面原型**，不接入生产路由，不影响 `console` 构建。

当前第一版覆盖：

- 统一身份登录页（SSO 登录、平台连接状态、应急入口占位）
- 应用壳：权限驱动的左侧导航、案件上下文顶栏、用户/角色菜单
- 案件研判工作台：消息、工具调用、数据表、参考依据、案件上下文侧栏、输入区
- 案件工作台：统计卡片、筛选、案件列表、进入研判
- 其余模块：信息架构占位页（文件、知识、数据、审批、收件箱、定时任务、技能、工具、用户与权限、审计）

## 启动

依赖复用 `console/node_modules`，不需要单独安装：

```bash
cd console
npm run design:dev
```

打开：

```text
http://127.0.0.1:5174
```

## 已做的交互

- 登录页点击“使用平台账号登录”模拟 SSO 登录，进入工作台
- 顶栏案件下拉切换当前案件，聊天与右侧案件上下文同步
- 左侧导航切换页面；管理员/普通用户视角由右上角用户菜单切换，普通用户隐藏“用户与权限”“审计日志”
- 聊天输入框可发送消息，模拟助手回复
- “参考资料”默认展示 3 条，支持更多/收起
- 工具调用卡片支持展开/收起步骤
- 案件列表点击行或“进入研判”回到聊天工作台
- 用户菜单“退出登录”回到登录页

## 设计方向

- 深墨蓝 + 暖灰 + 克制金色，强调权威、克制、信息密度
- 8px 网格、6–10px 圆角、细边框、轻阴影
- 中文正文以系统/思源黑体为主，避免“聊天机器人 Demo”感
- 默认浅色；后续可做深色指挥大屏变体

## 反馈方式

直接描述即可，例如：

- “导航太重，层级再少一点”
- “案件上下文应该默认收起，右侧只保留参考依据”
- “聊天区太宽，正文行长控制在 80 字以内”
- “登录页太像宣传页，再克制一些”
- “普通用户不应该看到技能和工具，改成按菜单权限显示”

修改后刷新页面即可看到效果；视觉确认后再逐步移植到 `console` 生产代码。
