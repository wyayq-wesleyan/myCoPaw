# Design Lab · 信息核查 v2

这是汇智小助手平台化改造前的**独立界面原型**，不接入生产路由，不影响 `console` 构建。

本轮范围覆盖**信息核查、办公助手、智能体管理、通知中心**，以及支撑它们的登录和首页。

## 启动

依赖复用 `console/node_modules`，不需要单独安装：

```bash
cd console
npm run design:dev
```

打开：

```text
http://127.0.0.1:5174
```

## 本轮已覆盖

### 登录与角色

- 所有账号统一走平台身份登录，不再单独设置本地管理员账号
- 是否具备管理能力由平台返回的角色决定，有管理角色即可维护智能体
- 原型默认登录账号同时具备管理角色，便于测试全部功能
- 顶栏用户菜单可切换管理角色 / 业务角色视角，便于演示

### 首页

- 四个独立模块：办公助手、信息核查、档案经营、信息监测
- 档案经营、信息监测为规划中占位
- 最近会话放在问候语下方，工作区上方
- 智能体管理、通知只保留在页面顶部，不再占用首页中间区域
- 管理角色同样可以进入案件业务，不再锁定模块
- 页脚固定在页面底部

### 信息核查

- 左侧分为三个 tab：案件、在控目标、文件树
- 案件 tab：案件详情、切换案件；搜索框只在切换案件时出现，选择后隐藏
- 案件选择支持多选、全选、反选和批量删除（仅从当前工作台移除，不影响案件系统）
- 文件树使用树组件：目录操作（新建子目录 / 上传到此处 / 重命名 / 删除）收在每行右侧 ⋯ 菜单
- 文件支持重命名、拖拽移动、移动到指定目录、预览
- tmp / res 为智能体固定目录，不提供操作菜单，不可改名、不可删除、不可移出
- 点击文件名打开预览抽屉（图片 / PDF / Markdown / Word / Excel / CSV / JSON / 文本）
- 在控目标 tab：每次点击都会重新请求当前案件目标，并显示刷新状态；超过 3 个时分页
- 文件树 tab：案件材料、上传文件、`tmp`、`res`，支持多选上传、文件多选和批量删除
- 点击文件名打开预览抽屉：图片、PDF、Markdown、Word、Excel/CSV、JSON、文本按类型渲染，和现版本汇智小助手的文件预览一致
- 去掉右侧历史栏，会话选择集成到输入框工具位，放在上下文用量左侧
- 中间工作区去掉任务计划，只保留：
  - 案件标题与在控目标摘要
  - 对话、工具调用步骤、固定结果模板、参考依据
  - 查询中心按批次返回审批需求；决策卡提供 `终止本次查询` / `发起审批`
- 查询审批请求条放在会话滚动区域内，不再悬浮在聊天区顶部
- 点击审批请求条会新开审批系统页面；原型中通过或驳回后，通过跨标签页消息更新小助手状态
- 审批通过后接入服务回调、结果入库，小助手在会话中展示结果
- 输入区：新建会话、附件、会话选择（上下文左侧）、上下文占比、模型、发送
- 聊天右侧悬浮导航：回到顶部、聊天记录（显示条数，点击展开记录列表）、回到底部
- 所有聊天区（核查、办公、智能体调试）共用同一套气泡、悬浮导航和输入工具栏
- 左侧栏可收起为图标栏
- 顶栏统一提供“返回首页 / 返回智能体管理”按钮

### 智能体管理

- 系统预设智能体由管理员维护，普通用户只读
- 普通用户可把系统预设复制为「自定义智能体」，之后自行增加知识库、技能、工具并调试
- 自定义智能体仅本人可见，可删除
- 支持卡片视图 / 列表视图切换
- 支持搜索、模块筛选、默认只显示可用智能体
- 列表按 6 个一页分页
- 管理员可多选、批量删除、删除、复制现有智能体
- 修改入口统一放在详情页，卡片上不再放“修改”
- 普通用户：预设 → 详情 / 复制为自定义 / 使用；自定义 → 详情 / 使用 / 删除
- 不支持从空白新建；需要新智能体时复制现有智能体后继续修改
- 普通用户只能查看详情和使用

### 智能体详情

- 左中右三栏布局
- 左侧菜单：知识空间、技能、工具、查询客户端
- 中间为问答调试区，与核查页共用气泡、悬浮导航和输入工具栏
- 右侧为智能体详情：名称、模块、模型、资源数量、提示词摘要、标签
- 管理员可更新知识文件、新建技能、工具、查询客户端，并编辑智能体基础信息
- “查询客户端”提供 MCP 配置：远程地址 / SSE 远程 / 本地进程三种连接方式，支持服务地址、请求头、启动命令、参数、工作目录、环境变量、启停开关
- 知识空间按智能体独立维护：上传、解析、向量化、重新向量化、删除
- 文档状态分：待解析 / 解析中 / 向量化中 / 已就绪 / 解析失败，并显示片段数
- 知识库跟随智能体，不复制到每个用户目录；用户使用时以只读方式挂载，管理员更新文档后所有使用者立即生效
- 案件产生的临时文件与结果仍写入该案件自己的 `tmp` / `res`，不写回智能体知识库
- 顶栏可返回智能体管理

### 办公助手

- 仿照信息核查：左侧文件树 + 中间聊天区
- 左侧只保留文件树，顶部为办公空间概览（资料 / 临时 / 结果计数）
- 文件树支持文件多选、批量删除和多选上传
- 聊天区与核查页共用气泡、悬浮导航（到顶 / 历史 / 到底）和输入工具栏
- 会话选择在输入框右侧，和核查页一致

### 通知中心

- 普通用户：审批 / 任务 / 通知三个 tab
- 管理员：只展示系统通知，不接收案件审批与任务通知
- 审批项提供“打开审批表单”入口
- 任务项可回到会话；通知项可去会话确认

## 设计方向

- 深墨蓝 + 暖灰 + 克制金色，强调权威、克制、信息密度
- 首页是模块入口，不再设置全局对话
- 进入模块后才出现该模块自己的工作区
- 中文标题使用宋体风格，正文使用系统黑体
- 8px 网格、6–10px 圆角、细边框、轻阴影
